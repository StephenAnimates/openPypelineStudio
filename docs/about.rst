=====
About
=====

**openPypeline Studio** is the modernized, Python-based successor to the original **openPipeline** framework, an open-source framework for managing animation production data and workflow.

It continues the original project's purpose but is a separate Python codebase, not the original MEL-based implementation.

Current status
--------------
Maya is the current supported integration. For details on implemented capabilities and other hosts, see :doc:`host_support`.

Contribute
----------
OpenPipeline's original website describes it as supported by the animation community. To contribute to openPypeline Studio, share how you use it, suggest improvements, or submit code and documentation through the `project repository <https://github.com/StephenAnimates/OpenPipeline>`_.

History & Origins
-----------------
First drafted as the *openPipeline Specification v0.1* in August 2007, its first implementation was a MEL-based plug-in for Autodesk Maya that handled specific aspects of production: automatic directory structures, file naming conventions, revision control, and modularity that makes multi-artist workflows possible.
